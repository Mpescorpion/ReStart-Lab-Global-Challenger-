📘 ReStart Lab+ — Plataforma de Requalificação Profissional

Projeto desenvolvido para a Sprint / Challenge — Turma do Bem + FIAP

📌 Sobre o Projeto

O ReStart Lab+ é uma plataforma proposta para apoiar a requalificação profissional de pessoas em situação de vulnerabilidade, oferecendo trilhas de aprendizagem acessíveis, módulos práticos, modo offline, catálogo de cursos e recomendações inteligentes.

O objetivo é criar uma experiência simples, intuitiva e acessível, simulando como o usuário final navegaria em um ambiente educacional real.

📂 Estrutura do Projeto

O site contém as seguintes páginas:

Home — visão geral do projeto

Sobre — explica o propósito, público alvo e pilares

Como Funciona — demonstra o fluxo de aprendizagem

Demonstração — simulação da plataforma, cards de cursos e painel do usuário

Catálogo de Cursos — cursos reais e fictícios

FAQ — perguntas frequentes

Contato — formulário e informações

Integrantes — membros do grupo
